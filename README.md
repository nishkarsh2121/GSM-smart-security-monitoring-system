# GSM-Based Smart Security and Monitoring System

## Overview

A smart security and monitoring system developed using ATmega328P and Embedded C. The system monitors motion, distance, and temperature using multiple sensors and sends SMS alerts through a GSM module.

## Components Used

* ATmega328P
* SIM800L/SIM900A GSM Module
* PIR Sensor
* HC-SR04 Ultrasonic Sensor
* LM35 Temperature Sensor
* 16x2 LCD with I2C Module
* Relay Module

## Features

* Motion detection using PIR sensor
* Distance monitoring using HC-SR04
* Temperature monitoring using LM35
* SMS alerts through GSM module
* Relay-based automation
* Real-time status display on LCD

## Technologies

Embedded C, UART, I2C, ADC, GSM Communication, Sensor Interfacing
